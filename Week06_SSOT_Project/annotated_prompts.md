# 提示词注解：拓扑投影与槽位规约

> 本文件记录将 Mermaid 思维导图线性化为 Markdown 章节大纲所用的关键提示词与约束，作为可复用的 SSOT（单一事实来源）提示工程样本。

## 一、拓扑投影提示词（用于大模型）

```text
你是一位精通金字塔原理与图论拓扑排序的科技期刊主编。
将剪枝确认后的 Mermaid 思维导图执行拓扑线性化投影，转化为 Markdown 章节大纲，
并细化指定章节的段落提纲与数据槽位规约。

约束：
- 严格按照“现象 -> 机理 -> 干预与实证 -> 结论与边界”的前置因果无缺原则，
  确立 4 个符合 MECE 准则的二级章节（##）。
- 为指定章节规划 3 个自然段，显式定义每段的修辞职责，
  并使用 [待填槽位：...] 标出所有需要后续注入的实验指标与样本参数。
- 严禁编造任何具体实验数值，严禁提前扩写完整段落正文。

验收：
- 章节排列满足概念先验依赖，不存在把后文概念提前引用的倒置现象。
- 清晰预留待填数据槽位，且未虚构任何统计百分比或耗时数据。
```

## 二、拓扑投影原则（图论 → 线性）

- **因果无缺（无前向引用）**：节点 B 若依赖 A 的概念，则 A 必须排在 B 之前。本课题依赖链为：
  熬夜现象（观察） → 沉迷机理（解释） → 干预与实证（验证） → 结论与边界（泛化）。
- **MECE 切分**：4 个一级章节互不重叠且共同穷尽论证空间（现象 / 机理 / 实证 / 边界）。
- **拓扑排序依据**：以思维导图中的放射分支为输入，按先验依赖做 Kahn 式线性化，输出有序章节序列。

## 三、数据槽位规约（占位符约定）

- **槽位语法**：`[待填槽位：<指标或参数名>]`，仅作占位，不承载真实数值。
- **三类槽位**：
  1. 样本参数（N、年级分布、分组方式）
  2. 主/次结局指标（入睡潜伏期、困倦率、褪黑素水平）
  3. 统计量（组间差值、置信区间、p 值、到课/签到时间）
- **禁则**：任何阶段均不得为槽位预填数值；数值须来自真实实验或标注为缺失。
