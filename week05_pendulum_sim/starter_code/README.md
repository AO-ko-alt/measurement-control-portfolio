## 🎯 任务四“闭环排错自愈”实操指南

如果在自主实验过程中，你的代码运行很顺利、控制台没有报错，可以使用本示范库进行 **全真自愈演练** ：

1. 双击打开 [03_buggy_practice/index.html](./03_buggy_practice/index.html)；
2. 在浏览器中按下 `F12` 键（Mac 为 `Command + Option + I`），切换到 **Console（控制台）** ；
3. 点击红色的 **“重置摆动 (点击报错)”** 按钮；
4. 控制台将立即抛出红色报错：
   ```text
   Uncaught ReferenceError: resetAnimation is not defined at HTMLButtonElement.onclick (index.html:125:46)
   ```
5. 复制这行报错，结合课件中的 **四段式自愈模版** 发送给 AI，观察 AI 如何调用编辑工具完成精准修复（修复后的结果对应 `04_fixed_solution/index.html`）。
