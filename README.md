## 四、每周实验怎么写？

打开对应周的 `实验说明.md`，建议包含：

1. **实验目的** —— 这周要弄懂什么；
2. **实验原理** —— 关键公式 / 电路 / 流程图（图放 `assets/`，用 `![图](assets/xxx.png)` 引用）；
3. **仪器与器材** —— 用了什么设备；
4. **步骤与数据** —— 操作过程 + 实测数据（表格或截图）；
5. **结果分析** —— 误差从哪来、怎么改进；
6. **心得** —— 一句自己的收获。
